Report a file

Use this form to report a file that breaks the Acceptable Use Policy or the law. Reported files are re-checked automatically right away. A person reads every email to abuse@bitsocialforge.com, so email us too when a report is urgent. Illegal files are removed at every link that points to them.

  • You can also email abuse@bitsocialforge.com, for example to include screenshots of where the file was posted.
